# Leader Cruises - Booking Management System (לידר הפלגות)

Это веб-приложение на React (Vite) для удобного оформления бронирований яхт и автоматической генерации сопроводительных документов.

## 🌍 Продакшен (Сайт онлайн)

Проект опубликован и автоматически обновляется по адресу:
👉 **[https://cruises-booking.pages.dev/](https://cruises-booking.pages.dev/)**

- **Хостинг:** Cloudflare Pages (Workers & Pages)
- **Репозиторий (Исходный код):** [https://github.com/Leader153/cruises-booking](https://github.com/Leader153/cruises-booking)
- **CI/CD:** Привязан к ветке `main` на GitHub. Любой `git push` в этот репозиторий автоматически пересобирает и обновляет сайт в интернете.
- **Настройки сборки:** Команда `npm run build`, папка вывода `dist`.


## 📌 Основной функционал

Приложение позволяет ввести данные о клиенте, яхте, датах и дополнительных услугах, после чего автоматически рассчитывает стоимость и генерирует ZIP-архив с 4 файлами:

1. `לקוח.txt` (Бланк для клиента)
2. `סופרוויזר.txt` (Бланк для супервайзера)
3. `אקסל_מפורט.csv` (Детализированный Excel файл)
4. `אקסל_סיכום.csv` (Итоговый Excel файл)

## 🚀 Запуск проекта локально

**Требования:** Node.js

1. Установите зависимости (если еще не сделали этого):

   ```bash
   npm install
   ```

2. Запустите сервер разработки:

   ```bash
   npm run dev
   ```

3. Откройте локальную ссылку `http://localhost:3000/` в вашем браузере.

Network: http://192.168.1.191:3000/
Убедитесь, что ваш мобильный телефон (или планшет) подключен к тому же Wi-Fi роутеру, что и компьютер.
Возьмите телефон, откройте мобильный браузер (Chrome, Safari и т.д.).
Введите в адресную строку телефона ровно этот адрес:
http://192.168.1.191:3000
Shortcuts
press r + enter to restart the server
press u + enter to show server url
press o + enter to open in browser
press c + enter to clear console
press q + enter to quit
